# UIスタイル一覧

分析画面では情報の役割ごとに以下の共通スタイルを選ぶ。定義は `src/styles.css` の `--ui-*` と `.ui-*` を正本とし、色やサイズを画面ごとに再定義しない。文章・データの意味や操作の有無は引き続き適切なHTML要素で表す。

| 役割           | クラス        | 用途                                                         |
| -------------- | ------------- | ------------------------------------------------------------ |
| 主要パネル     | `ui-card`     | グラフ、分析、戦績などの外枠。背景・枠・角・余白を統一       |
| パネル見出し   | `ui-title`    | `h3` / `h4` の見出し                                         |
| 項目名         | `ui-label`    | 数値を説明する短いラベル                                     |
| 主要数値       | `ui-value`    | 値や勝率。文字色は中立色とし、勝敗の意味は棒や塗りの色で示す |
| 小見出し       | `ui-subtitle` | パネル内の `h4` 見出し                                       |
| 補足           | `ui-note`     | 件数や算出上の注意。説明のためだけに不要な行を増やさない     |
| 見出し下の注記 | `ui-caption`  | 対象範囲や算出条件を示す、見出し直下の短い注記               |
| 英字の区分表示 | `eyebrow`     | パネル上部の補助的なカテゴリー名                             |

カード内の配置、グラフ固有の色、勝敗やエラーなど意味を持つ色は既存のコンポーネントスタイルで指定する。小画面では `ui-card` の余白を縮める。新しい情報を追加する際は、まず上記を組み合わせ、役割が一致しないときのみ共通スタイルの追加を検討する。

この一覧は分析パネルを先行対象とする。ヘッダー、フィルター、表などは既存スタイルを維持し、変更時に順次整理する。

数値や分布は、比較しやすい棒・位置・色と、正確な数値を組み合わせて表す。重複する説明文を増やさず、凡例や短いラベルを優先する。ただし、対象範囲、推定、欠損、少数サンプルなど誤解につながる条件は省略せず、短い注記やアクセシブルなラベルで伝える。色だけに意味を持たせない。

## 色の役割

データ表示の色は役割ごとに一つの意味だけを持たせ、`src/styles.css` のトークンで指定する。

| トークン         | 意味                                          |
| ---------------- | --------------------------------------------- |
| `--win`          | 勝ち、勝率50%以上、プラスの増減               |
| `--loss`         | 負け、勝率50%未満、マイナスの増減、苦手な対面 |
| `--neutral-data` | 引分・不明、データなし、「その他」            |
| `--series-lp`    | LPの系列                                      |
| `--series-mr`    | MRの系列                                      |
| `--text-strong`  | 数値や名称の文字。勝敗の色を文字に付けない    |

内訳の円グラフは、検証済みのカテゴリ色を固定順で使い、凡例で名称を示す。ライムの`--accent`はボタン、選択状態、接続状態などUIの状態表示に使い、勝敗以外のデータに使わない。1P・2Pの表示は識別だけなので中立色にする。

## 文字サイズ

文字サイズは `--ui-text-xs`（10px）、`--ui-text-sm`（11px）、`--ui-text-md`（13px）、`--ui-text-lg`（15px）、`--ui-text-xl`（20px）、`--ui-title-size`（23px）、`--ui-value-size`（26px）から選ぶ。ページ見出しなど一部の表示用サイズを除き、pxを直接書かない。英字の区分表示（`eyebrow`）は画面の大区分だけに付け、分析パネルには付けない。

## 内訳の表示

合計が全体になる内訳（勝敗、使用キャラクター、ゲージ使用割合）は円グラフと凡例で表す。凡例には名称と数値を必ず並べ、色だけで区別させない。区分が7つを超える場合は「その他」へまとめる。

## 余白

分析画面の余白は `--space-1`（4px）、`--space-2`（8px）、`--space-3`（12px）、`--space-4`（16px）、`--space-6`（24px）、`--space-8`（32px）から選ぶ。小さなラベル間は4〜8px、カード内の要素間は8〜12px、カード間は16px、パネル内の余白は24pxを基本とする。狭い画面では外側の余白を16pxに縮める。グラフ・表の描画座標など、情報表現そのものに必要な寸法はこの余白スケールとは区別する。
